# Craftables Jahus

Extra crafting, smithing and stonecutting recipes to **reduce waste** and unlock items that are normally uncraftable or hard to obtain.

[![Modrinth](https://img.shields.io/modrinth/dt/jahus-craftables?logo=modrinth&label=Modrinth)](https://modrinth.com/datapack/jahus-craftables)

## Equipment & gear

| Result | How |
|--------|-----|
| **Chainmail armor** (full set) | Crafted from iron chains |
| **Iron chain** | 3 iron nuggets (vertical) |
| **Saddle** | Leather + wool + string + iron |
| **Name tag** | Paper + string |
| **Iron / Golden / Diamond horse armor** | Shaped recipes with the matching material + wool |
| **Bell** | Sticks + iron chain + gold blocks + gold nugget |

## Tools: stone to iron upgrade

Upgrade a **stone tool** at the smithing table:

- **Template:** Flint  
- **Addition:** Iron ingot  
- **Result:** Matching iron tool (pickaxe, axe, shovel, hoe, sword)

Previous components (name, etc.) follow normal smithing_transform rules.

## Notes

- Goal: less dead-end loot (saddle, name tag, horse armor, chainmail) and more ways to recycle leftovers (arrows to sticks, wool to string, etc.).
- Stonecutter recipes go ways where it makes sense (e.g. stone to cobblestone).
